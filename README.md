# Stack Overflown

Stack Overflown 是一款以程式錯誤為主題的瀏覽器方塊益智遊戲。玩家移動、旋轉並放下不同形狀的方塊，在棋盤上拼出指定的錯誤圖樣；圖樣包括 Null Pointer、Memory Leak、Off By One 等。

## 遊戲功能

- 在 10 欄、20 列的棋盤上操作方塊，方塊會隨時間自動下落。
- 每回合顯示一個隨機錯誤圖樣。圖樣必須在棋盤任一個 5 × 5 區域中完全符合：圖樣需要方塊的位置必須有方塊，不需要的位置則必須留空。
- 成功拼出圖樣可得 100 分，並清空棋盤、產生新的目標圖樣。
- 方塊種類與顏色採用開發者主題；Void 方塊在圖樣比對時視為空格。
- 方塊堆到無法在棋盤頂端放入新方塊時，遊戲結束並顯示最終分數，可重新開始。
- 可隨時暫停或繼續遊戲。

## 操作方式

| 按鍵 | 功能 |
| --- | --- |
| ← / → | 向左／向右移動 |
| ↑ | 旋轉方塊 |
| ↓ | 加速下落 |
| Space | 直接落到底部 |
| P | 暫停／繼續 |

## 開始遊戲

使用瀏覽器開啟 [`src/index.html`](./src/index.html) 即可遊玩。此專案使用原生 HTML、CSS 與 JavaScript，無需安裝額外套件。
