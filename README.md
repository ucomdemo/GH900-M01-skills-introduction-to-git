# Stack Overflown

Stack Overflown 是一款以程式錯誤為主題的瀏覽器方塊遊戲。玩家需要移動、旋轉並放下方塊，在棋盤上拼出右側顯示的目標圖案；圖案取材自常見的程式錯誤，例如 Null Pointer、Memory Leak 和 Infinite Loop。

## 遊戲功能

- 隨機產生方塊，並讓方塊持續下落。
- 隨機指定一種 5 × 5 錯誤圖案作為目前目標。
- 拼出完整目標圖案即可得 100 分，清空棋盤並開始追逐下一個隨機圖案。
- 方塊堆到棋盤頂端時遊戲結束，並顯示最終分數。
- 可隨時暫停或繼續遊戲。

## 操作方式

| 按鍵 | 功能 |
| --- | --- |
| ← / → | 左右移動方塊 |
| ↑ | 旋轉方塊 |
| ↓ | 加速方塊下落 |
| Space | 直接放下方塊 |
| P | 暫停或繼續 |

遊戲結束後，選擇 **Restart** 即可重新開始。

## 開始遊戲

不需要安裝套件或建置。直接在瀏覽器開啟 [`src/index.html`](./src/index.html) 即可遊玩。

## 專案檔案

- `src/index.html`：遊戲頁面與介面。
- `src/index.js`：遊戲流程、方塊控制、計分與碰撞判斷。
- `src/patterns.js`：目標錯誤圖案資料。
- `src/style.css`：遊戲畫面樣式。
